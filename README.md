# backlot-landing

Landing page for **Backlot** — a writer's IDE for screenwriters and AI filmmakers.

Single-screen hero, static, zero build step. Brand system from laniameda Design System v2.0 (dark Obsidian theme, Darker Grotesque / Inter / JetBrains Mono).

## Run

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 8080
```

## Files

- `index.html` — markup
- `styles.css` — brand tokens + layout

The product app lives at https://github.com/Michailbul/backlot-app
